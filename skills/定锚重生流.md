## 套路概览

本模式适合"重生复仇 + 成长登顶"型长篇网文。核心机制是**锚定**：主角带着前世记忆重生后，不盲目乱闯，而是把"改写命运"这一总目标拆解为一个个可锚定的阶段性目标（复仇对象、境界门槛、秘境机缘、舞台名次、势力建立）。每一阶段沿同一闭环推进：

**信息差布局 → 底牌积蓄 → 小试牛刀 → 舞台兑现 → 收获新锚点**

同时以师徒、亲情、友情、爱情为情感锚点，以"宗门大比 → 演武大会 → 秘境洞府 → 狩猎竞赛 → 国战"逐级放大的舞台为展示窗，让主角每过一个阶段就向世界公开一层底牌、升级一重身份，最终从重生少年登顶为域界巨头。

一句话公式：**重生立誓 → 阶段锚定 → 信息差布局 → 底牌兑现 → 舞台扬名 → 情感收获 → 更大舞台**

## 阶段拆解

### 阶段一：重生锚定与立誓（约 1-10 章）
- **结构功能**：建立"信息差"设定，让主角与读者同步确认"我知道未来"，并立下贯穿全书的誓愿（守护 + 复仇），绑定核心情感对象。
- **常见信号**：重生回少年时代、散功重修特殊功法、通过入门考核、拜入关键师父门下、忆起前世惨状、对死敌立誓。
- **如何复用**：开局务必让主角"重历一次前世惨痛"以立誓，把复仇与守护绑定在具体人物（师门、父母）上，为全书每一次行动提供情感动机。

### 阶段二：底牌积蓄与首轮兑现（约 11-26 章）
- **结构功能**：展示重生红利（修炼速度、预知阴谋），完成第一轮小规模复仇，在宗门小圈子初次扬名，建立读者对"信息差有用"的信心。
- **常见信号**：快速突破、炼制一次性底牌、识破买凶/圈套、以身为饵诱杀、当众斩杀首个小反派。
- **如何复用**：首轮复仇规模要小、要快、要"名正言顺"（对方先动手），让主角第一战即展示"预知 + 底牌"组合拳，同时留一个悬疑钩子——反派临死吐露更上层线索。

### 阶段三：逆境传承与宗门舞台（约 27-78 章）
- **结构功能**：用一场"打压"（被罚/发配/问罪）把主角推入逆境，在逆境中解锁高级传承与身世秘密，再借宗门大比这类首个中型舞台集中扬威，完成第一次身份升级（被指定为继承人）。
- **常见信号**：因直言获罪、流放绝地、绝境悟道、传承考验、贵人赏识、大比一挑多、底牌暴露引发问罪、强者出面背书。
- **如何复用**：让"打压"与"机缘"成对出现——被发配之地恰恰藏着传承；每次底牌公开都伴随一次"问罪"，再用更强者背书化解，形成"亮牌—争议—背书"的循环。

### 阶段四：秘境循环与宗门危机（约 79-165 章）
- **结构功能**：进入第一个大秘境，获得标志性传承与宝物，实力跃升；随即以"师父失踪 / 宗门覆灭"制造全书第一记重挫，逼主角提前继任、扛起责任，并在绝境中越阶斩杀远超自身境界的强者。
- **常见信号**：秘境入口、傀儡/守卫考验、传承认主、假死/失踪、师父失踪、宗门被迫解散、继任仪式、牺牲角色、越阶斩杀。
- **如何复用**：秘境务必赋予主角一项"标志性传承"，成为后续实力的主轴；用"长辈失踪/陨落"把主角从被庇护者推上决策者位置。

### 阶段五：大型舞台与死敌循环（约 166-305 章）
- **结构功能**：主角离开主场游历，在大型舞台（演武大会）上与同辈天才争锋，经历"死敌现身 → 身边人被掳 → 悲愤爆发 → 屠灭仇家 → 身份合一"的完整循环，功法/宝物实现第一次大合并。
- **常见信号**：游历、蒙面死敌、结拜/切磋、身边人被掳（伪死讯）、夜袭屠戮、摆擂扬名、身份公开、终极对决、传承合并。
- **如何复用**：大型舞台要同时安排三类对手——切磋型天才（结友）、宿命死敌（功法同源）、势力型仇家（灭门对象）；"身边人被掳"是制造爆发力的标准装置，最好设计为"伪死讯"以留反转空间。

### 阶段六：家国战争与建宗立派（约 306-450 章）
- **结构功能**：把战场从个人恩怨扩大到家族/国家战争，完成与父母重逢、父子/母子并肩的关键情感桥段，通过战争胜利获得根据地与名望，为建宗立派铺垫。
- **常见信号**：拍卖会搅局、归家、灭地方势力、母子/父子重逢、幕后黑手揭示、大军团作战、城下之盟、国宴亮相。
- **如何复用**：战争幕的核心不是战争本身，而是"亲情重聚 + 幕后黑手上浮"；用一场决定性胜利换取"时间窗口"（盟约/停战），为下一阶段的潜修与建宗争取空间。

### 阶段七：洞府秘境与前辈营救（约 451-655 章）
- **结构功能**：主角正式建宗立派，进入全书最大秘境，历经多重选拔考验、获得决定性神兵，最终完成对"传说级前辈"的营救，获得最强靠山。
- **常见信号**：建宗、炼器、拍卖截胡、洞府开启、时间流速、法则考验、选拔赛制、神兵认主、强者下界、幻术拖延、联手破锁。
- **如何复用**：大秘境要设计成"选拔—晋级—夺宝—阴谋揭露"的多层结构；营救前辈的难点要设置成"锁链/禁制 + 看守者"双重障碍，用主角的成长（神兵、神通）与前辈的底蕴配合破解。

### 阶段八：复仇灭宗与大国博弈（约 656-892 章）
- **结构功能**：借脱困前辈的武力清算旧仇、灭敌对宗门，同时主角以"献宝/结盟"参与大国博弈，经历保卫战与狩猎竞赛等大场面，身份升格为域界级名人。
- **常见信号**：灭宗、幕后黑手揭示、祸水东引、献宝、谈判、保卫战、竞赛扬名、亦敌亦友对决、旧友重逢。
- **如何复用**：此阶段让"前辈武力"与"主角智谋"分工——前辈负责碾压式清算，主角负责布局（献宝引祸、结盟换资源）；每个灭宗/复仇事件都要牵出更上一级的幕后势力。

### 阶段九：域外流亡与回归定鼎（约 893-1025 章）
- **结构功能**：主角因追杀/阴谋被迫离开主场，经历"失踪—谣言—绝境突破—域外扬名—师徒重逢—满载而归—回归打脸—终极揭秘"的收束循环，在终极舞台一战定鼎并揭开身世终极之谜。
- **常见信号**：绝境逃亡、下落不明、谣言再起、困地闭关突破、域外战场扬名、师徒异域重逢、劫掠敌资、连斩扬威、一人破一国、渡厄大战、心魔幻境、身世揭秘。
- **如何复用**：末幕用"离开—归来"制造最大落差——主角失踪期间安排外界反应（谣言、势力态度反转），归来时一次性兑现全部累积（实力、宝物、人脉），并用"身世/心魔"完成主题升华，切忌以纯武力胜利结尾。

## 爽点节奏

- **压制—释放**：每幕开头压制主角（被罚、被诬、被困、失踪、丧亲之痛），每幕中后段释放（越阶斩杀、当众打脸、屠灭仇家、回归扬威）；压制与释放比例约 1:2，让读者始终处于"憋屈中期待、爆发时满足"的循环。
- **底牌递进**：一次性底牌 → 意境 → 意志凝聚 → 防御体系 → 法则 → 传承合一；规则是"每次公开一张牌，永远留一张未暴露的决胜牌"，终极对决才揭晓。
- **揭示节奏**：每幕至少一次"信息差揭示"——主角预知阴谋、识破卧底、认出蒙面死敌、看穿借刀杀人之计，让读者持续体验"我早知道"的智力优越感。
- **挫折设计**：最大挫折不来自战斗失败，而来自"失去"——师父失踪、宗门覆灭、身边人被掳、好友陨落；挫折之后必接一次实力跃升，形成"痛 → 强"的转化。
- **高潮分层**：小高潮（斩杀小反派/境界突破）→ 中高潮（舞台夺冠/灭宗）→ 大高潮（越阶斩渡厄/救出前辈/定鼎之战）；每 30-60 章一次中高潮，全书 3-4 次大高潮。
- **假死/失踪装置**：每卷中段安排一次"主角消失"（被宣告死讯/困于秘境/流亡域外），配以"外界谣言 + 势力态度反转"，为回归打脸蓄力；回归必配一个公开场合的扬威（连斩/一人破一国）。

## 角色功能模板

- **主角**：重生者，灵魂年龄远大于身体年龄；对外是天才少年，对内是冷静布局者；独有能力是"信息差 + 多底牌 + 越阶战力"。功能：承接所有爽点，同时承载情感锚点（为守护而战）。
- **导师/师父**：前期提供功法、庇护与暗中震慑（解决主角暂时打不过的敌人），中后期"失踪"逼主角独立，回归时提供武力兜底与情感高潮（师徒重逢）。
- **传说级前辈**：被镇压/失踪多年的顶级强者，与主角道统同源；功能是"终极靠山 + 隐藏线"——前期以传承（剑痕、遗言）形式存在，中后期被救出，成为碾压型战力与道德权威。
- **同辈盟友**：2-4 名，功能分三类——同门死党（陪伴成长）、切磋型天才（不打不相识）、异域盟友（带来新舞台信息）；定期重逢叙旧，见证主角成长。
- **亦敌亦友对手**：与主角实力相当的正面竞争天才，负责"竞争压力"与"互相成就"（对决后彼此进步），不承担恶行。
- **宿命死敌**：与主角功法同源/前世有仇，蒙面或伪装身份，层层递进（一个死敌的死亡牵出下一个更强的）；功能是"宿命感 + 终极对决"。
- **势力型反派**：宗门/国家/幕后黑手，构成反派阶梯——小反派（当前舞台恶人）→ 中反派（家族/宗门）→ 大反派（幕后道统/黑手）；每次复仇兑现都要让幕后上浮一层。
- **红颜/同伴**：情感线角色，承担"被掳—营救"、心魔治疗、见证身份等剧情功能；注意给独立人格与成长线，避免纯工具化。
- **父母/家人**：亲情锚点，前期是主角守护的对象，中后期战场重逢、并肩作战，是"主角为何而战"的最终答案。
- **牺牲角色**：1-2 名，在关键战役以命换胜/缠住强敌，其遗言/遗物成为主角后续行动的动力，制造全书最重的情绪锤。
- **工具角色**：城主、执事、眼线、商贾——提供信息、资源、打脸对象，或成为"主角身份"的见证者与传播者（把主角战绩轰传各方）。

## 可复用叙事规律

1. **信息差有保质期**：前世记忆只在前 30%-40% 篇幅内可靠，随着蝴蝶效应（主角改变历史导致未来偏离）逐步失效，逼主角后期靠真实力取胜——这既是合理性也是成长弧线。
2. **每个舞台配一个"验证时刻"**：宗门大比、演武、洞府选拔、狩猎竞赛都是主角向世界"公开验证实力"的场合；舞台名次/战绩要可量化（一挑四、连斩七人、千分夺魁），方便传播与对比。
3. **身份逐级解锁**：弟子 → 继承人 → 宗主 → 世子/域界名人 → 巨头；每升一级解锁新的资源、话语权与责任；身份公开要选在最有效果的场合（国宴、大比、归宗）。
4. **底牌三原则**：a) 底牌来源必须提前铺垫（功法、宝物、传承在前文出现过）；b) 底牌公开后要有"问罪/争议—强者背书"的回收；c) 永远保留一张全书未用过的决胜牌。
5. **反派阶梯规则**：每打倒一个敌人，从其遗言/书信/同伙口中牵出上一级幕后，形成"打怪升级 + 幕后揭开"双线；幕后黑手揭示不能早于全书 70%。
6. **情感锚点轮换**：每幕至少一次高质量情感戏——师徒（传功/重逢/失踪）、亲情（母子相认/父子并肩）、友情（结拜/辞别/重逢）、爱情（守护/心障）；情绪戏与爽点戏交替，避免连续三章纯打斗。
7. **假死/失踪配套规则**：主角失踪期间必须给出"外界视角"（谣言、势力态度、敌人嚣张）——读者知道真相而书中人不知道，形成信息差爽点；回归时谣言不攻自破。
8. **传承体系主轴线**：每个大阶段给主角一项"标志性传承"，这些传承最好同源（同一道统/同一强者的遗产），构成实力主轴的可见成长曲线。
9. **舞台升级公式**：每个新舞台的规模、围观者层级、对手境界、奖励层级都比上一个翻倍，且主角在舞台上公开的内容要比上次多一层（实力、身份、宝物）。
10. **终极揭秘前置埋线**：身世之谜、幕后黑手、功法源头等终极秘密，须在前 70% 篇幅埋下至少 3 处线索（遗言、遗物、梦境、他人只言片语），末幕一次性回收。

## 使用注意

1. **必须更换全部表层设定**：境界名称、功法名、宗门/国家名、人物名、宝物名全部重写，只保留结构关系（师父—弟子、道统传承、死敌循环）。
2. **重生红利必须设限**：明确写出"前世记忆失效的边界"（蝴蝶效应、超出前世范围的事件、被强者遮蔽的天机），否则主角永远开挂，读者会疲劳。
3. **假死/失踪循环节制使用**：每卷最多一次，且每次的"消失原因、突破内容、归来方式"要差异化（被困 → 流亡 → 假死），避免公式化。
4. **大型舞台要差异化**：宗门大比靠实力碾压、演武靠死敌对决、洞府靠机缘解谜、狩猎靠战术协作、国战靠布局调兵——不能五个舞台都写成"擂台连战"。
5. **情感线要有独立价值**：红颜/同伴不能只为"被掳—营救—撒糖"服务，要给出独立动机、成长与选择（如自我封闭的心牢、主动辞别的道别），否则沦为工具人。
6. **灭宗/屠戮桥段需道德校准**：给主角"师出有名"（对方先掳人、先背约、先灭门），并安排"罪不至死者获宽宥"的对比细节，避免主角沦为滥杀者。
7. **武力体系要自洽**：越阶斩杀必须有明确理由（底牌/克制/前辈加持），且要付出代价（重伤、散功、闭关），否则战力系统崩坏。
8. **终极秘密不能临场硬造**：身世、幕后黑手、功法源头必须在前期埋线；若作者边写边编，至少在中段补插"回溯性伏笔"，不能让读者感到突兀。
