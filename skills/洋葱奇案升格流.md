## 套路概览

本模式的内核一句话：**每一桩鬼案都是一层洋葱皮——主角剥完一层，发现后面还套着一层更大的阴谋，直到洋葱芯里埋着的，是主角自己的身世与整个世界的真相。**

它由两套互相嵌套的结构驱动：

1. **卷内循环（最小可复制单元）**：一宗"看上去能自理"的诡异凶案 → 追凶溯源 → 打倒台前凶物 → 反转出上一层黑手 → 借朝廷/大势力之力 → 总攻决战 → 高层摘桃风波 → 战利品升级并抛出下一案钩子。整个故事由多个这样的"卷"串联而成，每一卷只比上一卷高一层、大一级。
2. **全书洋葱（宏观骨架）**：卷案挖出的黑手呈阶梯式升级——从"地方邪物遗祸"一路指到"朝廷本身即黑幕"，主角在其中不断升官、升境界、升身世认知，最终以"牺牲自己守护规则"完成闭环。

### 洋葱层级抽象模板（层级 → 抽象定位）

| 层 | 抽象定位 |
|---|---|
| 台前凶物 | 守"规矩"的超自然凶器，是本卷明面敌人 |
| 区域黑手 | 上古/前朝人物遗留的祸根 |
| 江湖组织 | 有"夺舍、血食、造神"招牌招式的跨卷串联者 |
| 拱卫系统 | 与主角同体制却各怀鬼胎的"自己人" |
| 庙堂格局 | 表面分权、实为牵制主角的官方天花板 |
| 王朝顶层 | 终极黑手，主角一切案件的最终源头 |
| 主角自身 | 洋葱芯：身世与结局绑定 |

写作时把这一列职位整体换皮，即可得到新的世界观层级。

## 阶段拆解

本模式有**两个粒度**：先看每卷内部的"标准循环"，再看全书把循环不断放大、升维的"宏观骨架"。

### A. 卷内标准循环（八拍）

原型卷：**卷一（约1–58章）**。此循环在后续各卷（约60–176章、约178–240章、约242–302章、约304–332章、约336–364章、约390–482章、约484–554章）中反复复制并逐级放大。

| 拍 | 功能 | 常见信号 | 如何复用 |
|---|---|---|---|
| 1 奇观命案开场 | 用"不可能的死法"瞬间立起世界观与恐怖感 | 新地图连发怪案；死者死法违背常理且留有"仪式痕迹"；官府束手 | 每卷发明一种全新凶器/民俗机制，开场一章内给出一个视觉冲击极强的死亡场景 |
| 2 主角炫技验尸 | 展示主角过人之处，顺带揭示"凶器守规则" | 验尸推断死因与刑名/蛊道/法术条文对应；指出"它不能杀XXX"的豁免条款 | 让主角把破案做成"研究规则"而非蛮干，当场讲出凶物的行为准则与漏洞类型 |
| 3 结伴追索 | 换地图赶路，沿途布民俗惊悚小单元，展开队友副线 | 客栈/驿站/渡口遇险；同行者身世若隐若现 | 每个途经地点塞一个独立小怪谈，同时揭一个队友的秘密（身世/仇怨/真实身份） |
| 4 伪解答·台前Boss | 抓住"凶手"，卷内小高潮 | 凶手竟是受害者/被操控者/保护者；凶器被拆但祸根未除 | 让台前凶物本身也是棋子，打完只算"剥了半层皮" |
| 5 反转·暴露上一层 | 真黑手现形，卷内最大认知落差 | 主谋是随行参谋/恩人/向导/老鸨等"自己人"；亮出教派/组织的信物腰牌 | 把背叛者藏在主角团队或利益方内部，身份揭晓时回闪其全部伏笔 |
| 6 借势布局 | 主角向上借力、把更大的势力拖下水 | 伪造圣物/官身；设计让大人物被迫卷入；以"规则豁免"破局 | 主角主动"自伤/示弱/卖惨"换取布局空间，让大佬在利益上与主角绑死 |
| 7 总攻决战 | 大规模场面收束，牺牲者高光 | 大军/群豪围攻据点；关键配角自请赴死并留下遗物遗志 | 总攻前给牺牲者一次完整回闪，死法要仪式化，死因要换得主角方战略转机 |
| 8 摘桃反制+升级钩子 | 卷末定调：赢了不算赢，能顶住"上头分功"才算赢 | 高层同僚抢功/抢宝/问罪；主角亮出早已备好的后手；吞下战利品突破境界 | 结尾固定三件套：立威、升级、抛出一条身世或黑幕新线索 |

### B. 全书宏观骨架（八阶）

以下按全书推进顺序，把"卷内循环"叠成一部完整长篇。括号内为约章节范围。

**第一阶：奇案立世，定调定规（约1–8章）**
- 结构功能：一开场就让新地图连丧要员，确立"官府管不了灵异案、需要特殊衙门"的世界观；主角以"编外/见习/异类"身份入场，立即展示验尸推理的降维打击，并确立"凶物守规则、规则有漏洞"的全书破局法。
- 常见信号：连换数任官职皆死；奇观级死法当众上演；凡人官僚集体恐惧。
- 如何复用：开局案必须是"可以收尾的样板案"，作用是教会读者这套世界的玩法，而非真正解决主线。

**第二阶：追凶之旅，团队成型（约10–28章）**
- 结构功能：把"案"变成"旅"。沿途用数个民俗恐怖单元累积线索，逐步逼近第一个台前Boss的巢穴；此阶段完成主角心结袒露、同伴归心，并借队友秘密（双胞胎/冒名/忍死续命）引出第一层黑手。
- 常见信号：追查旧地/祖籍/巢穴；每经一地灭一村；揭同伴真实身份。
- 如何复用：让追查本身成为"观光恐怖公路片"，每个停靠点既推进主线又丰满一人。

**第三阶：借势破局，拉大人物下水（约30–40章）**
- 结构功能：主角实力不足硬撼Boss，转用智取——伪造圣物、制造事件、把王侯级人物拖入战局，顺势获得兵马、装备、传承。同时安放一名"自知命不久矣"的牺牲者，为总攻蓄势。
- 常见信号：夜探取血失败；索性点燃引子主动召敌；大佬被迫参战；出征前分宝传刀。
- 如何复用：让主角的每次求助都不是"求人"，而是"设局让对方不得不出手"，维持主角的掌控感。

**第四阶：总攻揭幕，真黑手现形（约42–57章）**
- 结构功能：大场面攻城战中插入"我方参谋才是黑手"的背叛反转；主角冷眼识破、以早已暗调的精锐后手翻盘，但结局仍是惨胜——自己被困/被抓/被更大的力量收割。
- 常见信号：血月/大军/尸潮；主谋自曝动机并嘲笑众人是血食；主角历数对方破绽令其心态崩溃。
- 如何复用：总攻必须同时完成"台前Boss伏诛"与"更大黑手登场"两件事，让卷末胜利带刺。

**第五阶：摘桃反制，归衙立威，吞利升格（约59–64章）**
- 结构功能：战后清理战场与功勋归属。同僚高层来抢功、抢宝、逐人，主角亮出"早已兑现的暗手"（如重伤了对方主事者）当场立威；收编同伴、吞下战利品突破境界，为下一卷储备实力与身世钩子。
- 常见信号：讨功者上门；当众羞辱主角部下；主角祭出伏笔反杀；新杀招练成但被斥为禁术。
- 如何复用：每卷结束都要有一场"体制内的余波"，它是区别于纯打怪流的关键——主角永远活在江湖与庙堂的夹缝里。

**第六阶：洋葱升维，卷循环逐级放大（约60–364章）**
- 结构功能：五到七个"卷内循环"依次展开，每卷对手的社会层级抬高一级，同时卷间用暗线缝死：同一部邪功残卷、同一个跨卷组织、同一件失物/旧案反复冒头。
- 常见信号：新案与旧案同源；反派使主角方独门秘技；旧Boss的名字在档案/遗言/器物中复现；每卷末主角的"合法身份"升一级（散捕→镇抚→御赐身份→巡按）。
- 如何复用：把每卷的黑手对应洋葱阶梯的一层，让读者意识到"上面还有人"；卷与卷之间必须有一根不断被拉紧的串线（功法/组织/人物），否则会散成单元剧。

**第七阶：双重清算，绝境重生（约366–388章与约556–588章）**
- 结构功能：全书在情感与阵营两个维度各设一次"釜底抽薪"：先让情感锚（挚爱）被敌方利用而死/入魔，主角黑化后被迫自封记忆；后让主角的大本营（师门/同僚）被终极势力屠灭，四将殉道悬尸。两次清算把主角逼到一无所有，再用"自残献祭重生"（自断臂眼、以血起誓召神、获授终式）完成人物的破而后立。
- 常见信号：亲人/旧部之死成为主角质变开关；主角以官身血洗仇家；本营屠村级惨案；绝境中献祭自我换取力量。
- 如何复用：情绪重锤不能多，全书最多两到三次，且必须砸在不同维度（一个砸感情，一个砸归属），否则读者免疫。

**第八阶：身世总揭，终极对决，牺牲闭环（约590–614章）**
- 结构功能：把"洋葱芯"整个剖开——主角的身世、穿越者的真相、王朝的伪史、自身功法与"关门"命运的由来一次性引爆；随后全书最大决战；结尾主角以"必须有人守规则"为由自我牺牲，兄弟/继承人接手传承，并留一句穿越时间的情感呼应闭环。
- 常见信号：密档与旧人口述双线印证身世；终极Boss在前期以战友/上司身份出现过；决战需主角开某种"门"；结局牺牲带有仪式性与对称性（开篇何来，结尾何去）。
- 如何复用：终局三件事——把前面所有卷的钩子一次回收、让主角的宿命与开篇设定首尾咬合、留一个"后继者视角"的余韵收尾。

## 爽点节奏

### 卷内节奏（以约50–110章为一卷计）
- **压制**集中在开卷与中段：开卷是灵异恐怖压制全场（连死要员、当众分尸）；中段是中层强敌压制（铜尸、刑具、蛊毒围困），保证每卷有两次"喘不过气"的段落。
- **释放**紧跟压制：验尸推理打脸庸官、识破幻象/鬼阵/冒名、钻规则漏洞破局——凡"主角开口讲规则"即爽点。
- **揭示**卡在每卷两处：第4拍"伪解答"给一次小揭晓（凶手竟是受害者），第5拍"真黑手"给一次大揭晓（主谋是身边人）。两揭之间相距约10–15章。
- **挫折**固定一次：牺牲者赴死或同伴重伤、主角被阴/被困，出现在总攻前或总攻中，用来垫高随后总攻的情绪。
- **高潮**双叠：第一叠是总攻屠Boss（群体热血），第二叠是"摘桃风波反制"（个体扬眉）。第二叠才是卷末真正的爽点落点——"打赢不算赢，能顶住上头分功才算赢"。
- **钩子**永远在最后一页：一条身世线或黑幕线的新线索，逼读者翻卷。

### 全书节奏
- 三线错峰推进，每卷至少推进一条：**武力境界线**（从凡俗一路破境，乃至以诡异之躯重生）、**势力版图线**（散捕→借兵→御赐身份→执掌一方）、**身世认知线**（穿越者→弃婴→皇子→宿命守护者）。
- 用三次"心理重置"防止卷案套路疲劳：约366–388章情感重锤、约556–588章阵营覆灭、终卷自我牺牲。每次重置都先把主角打回谷底再抬升。
- 越往后，爽点重心从"推理炫技"逐步让渡给"权力算计"再到"热血牺牲"，防止读者看腻同一种爽。

## 角色功能模板

| 功能位 | 定位与写法要点 |
|---|---|
| 主角 | 底层阴差+身世炸弹。**主动布局者**：示弱、自伤、断后、被骗入局，都是为了换布局空间；技能获取绑定剧情事件（吞噬战利品、濒死献祭、继承遗志），绝不靠打坐升级 |
| 兄弟型搭档 | 情感喜剧担当+身世镜像（胎记/滴血认亲都落在他身上）+肉身抗线；专打"主角不肯打的狠仗"（燃血、搏命拳法）；最后接棒主角的位置完成传承闭环 |
| 情感锚 | 从同伴升级为弱点，被敌方反复用作要挟筹码；死亡/入魔/被牺牲是主角黑化的唯一合法扳机；以一句"来生"式遗言留下全书最大刀片 |
| 半盟友高层 | 立场暧昧的官方天花板，可"欠人情"也可"还人情"，在主角闯祸时提供合规保护，在主角得势时制造掣肘 |
| 台前Boss | 超自然凶器化的棋子，遵守某套可被研究的"法"，本身多是被利用的受害者 |
| 跨卷黑手 | 有招牌邪功（夺舍/血食/造神）与明确的大计，负责把所有卷串成一根绳 |
| 终极黑手 | 前期以"战友/上司/恩人"面目出现，揭晓时完成全书最大信任崩塌 |
| 牺牲者 | 自带秘密身世，赴死前回闪给全（身份、绝技、牵挂、遗物）；死法仪式化，死亡必须为主角方换来战略转机 |
| 导师/传功者 | 疯/残/被囚长者，临终渡功+授终极一式，同时兼任"身世与世界观解说员" |
| 工具人矩阵 | 每卷按案情发一套专业工具人：伪造者、开锁者、地图者、情报者、运力者；工具人同时是案件入口 |
| 摘桃竞争者 | 体制内同僚高层，战后抢功抢宝抢人，逼主角当众亮后手——是"庙堂爽点"的引信 |
| 双面揭穿者 | 每卷安插一个"看似自己人"的冒名/借尸/内鬼，维持全卷"身边谁是鬼"的张力 |

## 可复用叙事规律

1. **超自然必须守规矩。** 给每个凶物立一套"准法律则"（刑律、蛊道、符咒仪式、机关法则）。Boss越强，破绽越在"规则漏洞"而非硬刚。主角的定位是"研究规则的人"，全书所有胜利的第一因都是"钻了规则的孔子"。
2. **漏洞类型不许重样。** 圣物豁免、官身豁免、认亲豁免、名字相合豁免、献祭豁免、正气豁免……逐卷轮换。同一招用两次立刻贬值。
3. **主角的胜利要提前埋单。** 总攻前多手布局（暗调精锐、飞鹰传讯、事先伪造好替身与假物、预先重伤对方主事者），战后一次性回收，让读者回翻时恍然大悟——主角"被打得很惨"的画面往往是布局的一部分。
4. **每卷必有一场"自伤换棋"名场面。** 主动断后、引火烧身、血肉挡蛊、被穿胸冻成冰雕。用看得见的惨换看不见的先手，既赚同情又立智谋。
5. **验尸是最高效的信息通道。** 死者身份、旧伤、随葬物、发丝、尸料都是破案钥匙；"凶手其实早就死了/是冒名顶替/是借尸还魂"是最便宜也最好用的反转。
6. **阵营里必有"别人送来的棋"。** 每卷安插一个带秘密的同行者，其秘密在中段揭开并反转与主角的关系（队友→仇家之后、参谋→主谋、恩人→宿主）。
7. **名分即武器。** 官身、御赐、皇子身份反复改变战局。主角每卷升一级"合法身份"，身份本身就是剧情奖励与下一卷的入场券。
8. **升级必须做成仪式化死局。** 濒死献祭（自断臂眼、燃血召神）、继承遗志（取回遗物、吞血晶）、吃下战利品。把数值成长全部翻译成可记忆的场景。
9. **牺牲者要先"给全"再"收走"。** 赴死前交代身世、绝技、牵挂、遗物归属；死法要带仪式感（最后一击断台、钉入后脑、含笑毁器）。只死不给，等于白死。
10. **"打赢了不算赢"是固定第二高潮。** 每卷战后安排高层讨功、抢宝、逐人，主角以"早已备好的后手"或"当场立威"反制——这是灵探与庙堂题材区别于纯冒险流的核心爽点。
11. **身世要像挤牙膏。** 穿越、弃婴、滴血相溶、胎记、名字宿命、养母血脉……每个身世碎片卡在关键卷末抛出，配合"主角失忆/被抹记忆"制造全书最大悬念。
12. **大Boss死于自己的执念或规则。** 用攻心（历数破绽令其崩溃）、引蛇出洞（诱其夺舍假物）、钻规则空子（皇亲圣物豁免）收尾，而非纯武力碾压——保持"主角赢在脑子上"的统一性。
13. **明暗双线推进。** 反派阵营（邪教大计、秘密卫队布局）也在按自己的计划行动，主角只是被卷进其中的一环；要让读者看见"两边都在下棋"，而不是主角单方面破案。
14. **旧账要在N卷后翻案。** 前期随手埋的细节（"求死不能"的酷刑、失踪的旧部、被盗的残尸）在十几卷后以"原来当初那句是伏笔"的方式引爆，制造长线追读的回报感。

## 使用注意

以下为使用时需要重点注意的地方：

- **凶器/民俗机制必须全新原创。** 每卷的"核心创意"是生命线，严禁卷间复用同一机制，务必保证原创性。每卷的核心凶案机制应能做到"一句话讲清、画面感极强"。
- **洋葱阶梯要整体换皮。** 不要总是"江湖邪教→秘密卫队→皇帝本身"的路线。可换成"宗门→商会联盟→藩王割据→上古神朝"，或"巫族→军阀→陨落天庭"。层级数约5–7层，揭开顺序需重新排布，尤其"终极黑手=曾在主角身边的自己人"这个设定要设计出不同的身份方案。
- **主角身世配方要重新搭配。** 名字相合、胎记认亲、滴血相溶、弃婴收养、夺舍母脉、被抹记忆——这些零件可自由组合，但组合结果、揭晓节奏、由谁揭晓都必须另起炉灶，尤其避免"女主滴血认亲拉男主认祖归宗"这类场景被原样复刻。
- **两记重锤的目标与时机要定制。** 不必是女主惨死、不必是大本营被屠村。虐点必须对准你自己故事的情感重心（师徒、故国、族群皆可），且全书最多两到三次，位置要服务于你的主线，不必套用固定的重锤时机。
- **摘桃者与"体制"要换物种。** 隔壁衙门女官抢功、御前讨封这类桥段可保留结构，但竞争者身份、规则细节（是比功勋牌还是比讼词还是比战绩）要重新设计。
- **卷内八拍的顺序可压缩、可调换。** 有的卷可删掉整段"借势"（如进入后期主角已成气候），有的卷可把"真黑手反转"提前到卷中；模板是骨架，不是章节目录，要防止读者一眼识别出"哦，第X卷又该摘桃了"。
- **感情线必须重写。** "见习搭档→被掳要挟→饮魔血→撞刀自尽→黑化遗忘"这条链辨识度极高，只保留"情感锚被用作弱点"的机制，具体人物关系、死因、主角的反应方式都要自建。
- **境界与力量体系要自建。** 升级事件可借鉴"吞噬+献祭+继承"的思路，但数值框架、突破条件与境界命名需独立设定。
- **终局牺牲要与你的开篇设定咬合。** "主角开篇因何而来，结尾就必须因何而去"（即开篇人设与守门命运呼应）。若你的主角没有这种开篇即埋的宿命，结尾就不要强行牺牲，否则情感不成立。
